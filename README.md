# My Portfolio

Personal portfolio website of Krzysztof Dobosz, built with React and React Bootstrap.

Live: https://krzysiekdobosz.github.io/My-Portfolio

## Running locally

```bash
npm install
npm start
```

## Scripts

| Command          | Description                                  |
| ---------------- | -------------------------------------------- |
| `npm start`      | Development server on http://localhost:3000  |
| `npm test`       | Runs the tests                               |
| `npm run build`  | Production build in `build/`                 |
| `npm run deploy` | Builds and publishes to the `gh-pages` branch |
